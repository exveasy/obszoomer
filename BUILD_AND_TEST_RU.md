# OBS Smooth Zoom — как собрать и протестировать на Windows

**Важно:** в этом архиве исходный код, DLL появится только после успешной Windows-сборки. На Linux здесь проверены лишь независимые тесты геометрии, не работа в OBS.

## Вариант А. Собрать без Visual Studio через GitHub Actions (рекомендуется)
1. Создай пустой репозиторий на GitHub, например `obs-smooth-zoom`, и загрузи **содержимое** этого архива, сохранив папку `.github/workflows`.
2. Открой вкладку **Actions → Build OBS Smooth Zoom for Windows → Run workflow**. Сборка также запускается при push в `main`/`master`.
3. Если сборка завершилась зелёным, открой её и в разделе **Artifacts** скачай `obs-smooth-zoom-Windows-x64`.
4. Распакуй внешний архив артефакта: внутри должен быть `obs-smooth-zoom-Windows-x64.zip` с двумя папками `obs-plugins` и `data`.
5. Закрой OBS и распакуй содержимое этого **внутреннего ZIP** в каталог установки OBS (обычно `C:\Program Files\obs-studio\`).

При ошибке сборки открой красный шаг и сохрани текст ошибки, начиная с первых строк `error` / `CMake Error`, — по нему можно исправить проект.

## Вариант Б. Собрать локально на Windows
Нужны **Git**, **CMake 3.28+**, **Visual Studio 2022** с рабочей нагрузкой «Desktop development with C++» и **Windows SDK 10.0.22621**. Не требуется устанавливать Qt и компилировать OBS вручную: CMake шаблона OBS загрузит и подготовит зависимости автоматически. Первый запуск загружает большие файлы из интернета.

Открой PowerShell в папке распакованного исходного проекта и запусти:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Build-Easy-Windows.ps1
```

При успехе появится `dist\obs-smooth-zoom-Windows-x64.zip`. Можно запустить установку из PowerShell **от имени администратора**:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Install-Test.ps1
```

Либо закрой OBS и вручную распакуй `dist\obs-smooth-zoom-Windows-x64.zip` в `C:\Program Files\obs-studio\`.

## Первый тест в OBS
1. Перед тестом **сделай резервную копию коллекции сцен**. Тестируй без активной трансляции.
2. Запусти OBS Studio в обычном режиме (не портативную копию с другими путями установки).
3. Проверь меню **Инструменты → OBS Smooth Zoom...**. Если его нет — **Справка → Файлы журнала → Просмотреть текущий файл журнала**, найди `obs-smooth-zoom` или `Failed to load`.
4. Создай тестовую сцену, добавь свою **камеру**. Выдели источник камеры **одним кликом** в списке «Источники». Отключи **Режим студии** на первый тест.
5. Наведи указатель на изображение в предпросмотре, прокрути колесо вверх/вниз. Картинка **внутри области камеры** должна изменять масштаб, остальные объекты сцены — нет. Фильтр `OBS Smooth Zoom` автоматически появится в списке фильтров камеры.
6. Проверь приближение к углу изображения и обратно. Дважды нажми колесико для сброса масштаба (двойной средний щелчок).
7. В меню **Инструменты → OBS Smooth Zoom...** попробуй режим `Ctrl + колесико`, скорость зума и анимацию.
8. Сделай 10-секундную **локальную запись**, проверь, что масштаб изменяется в полученном видео, а не только в предпросмотре.
9. Убедись, что при переключении на другие сцены ничего неожиданно не меняется. Важно: **один и тот же источник камеры** имеет общий фильтр во всех сценах, где он используется.

## Если возникнет проблема
- **OBS не запускается**: удали `obs-smooth-zoom.dll` из `obs-plugins\64bit`, затем запусти OBS снова. Восстанови `.bak`, если она была создана.
- **Меню нет**: открой OBS log, проверь строки загрузки плагина; убедись, что DLL для x64 и папка `data\obs-plugins\obs-smooth-zoom` присутствует.
- **Зум не работает**: убедись, что выбрана видеокамера, она не заблокирована, включен предпросмотр, выключен Режим студии, курсор внутри предпросмотра.
- **Чёрный экран / ошибка эффекта**: проверь путь `data\obs-plugins\obs-smooth-zoom\zoom.effect` и покажи соответствующие строки OBS log.
- **Неудобная работа зума**: пришли версию OBS (Справка → О программе), лог, результат теста, а также тип сцены/камеры.

Скрипт сборки получает официальный шаблон `obsproject/obs-plugintemplate` с GitHub на момент запуска и преобразует его во временном каталоге `.obs-template-build`; его изменения не перезаписывают исходники проекта.
