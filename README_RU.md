# OBS Smooth Zoom 0.1 (Windows x64)

Нативный плагин для OBS Studio 29.1+ (Qt 6).

**Функции:**
- Выдели источник **камеры** в панели «Источники» OBS.
- Наведи мышь на область предпросмотра.
- Колесо вверх — приблизить; вниз — отдалить. Работает в трансляции и записи.
- Двойной клик **средней кнопкой** — сброс до 1×.
- Зум по курсору; плавность настраивается; максимальный масштаб до 10×.
- Меню **Инструменты → OBS Smooth Zoom...**: шаг увеличения, максимум, время анимации, переключение на Ctrl+колесо, центрирование.
- Зум происходит **внутри границ самой камеры**. Остальные элементы сцены не двигаются.
- Первая прокрутка добавляет в камеру фильтр `OBS Smooth Zoom`. Можно убрать его в «Фильтры» источника для полного отката.

## Примечания
- Работает с **одним выделенным видеоисточником**; групповые источники пока не поддерживаются.
- Если один и тот же источник камеры используется в разных сценах, фильтр действует на этот источник везде. Для независимого зума на разных сценах используй отдельные источники/копии.
- В Studio Mode зум применяется к выбранному источнику **Preview**, поэтому при разных сценах Preview/Program он не обязательно сразу виден в Program. Это ожидаемое поведение OBS.
- Настройки сохраняются в пользовательском профиле; состояние зума хранится в фильтре источника и сохраняется со сценами.
- Не захватывает колесо в других областях OBS. Если источник не выделен, поведение колесика остаётся штатным.
- Первоначальная версия, возможны несовместимости с нестандартным масштабом Preview или некоторыми трансформациями.

## Сборка
Этот ZIP — **исходный проект**, НЕ готовый `.dll` и НЕ инсталлятор: необходимы OBS SDK / собранный OBS, Qt 6, Visual Studio C++ и CMake. На машине, где есть эти зависимости:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build-windows.ps1 -ObsSdk 'C:\obs-build' -QtPrefix 'C:\Qt\6.8.3\msvc2022_64'
```

Указанные пути — примеры, замени своими. Скрипт сформирует `obs-smooth-zoom-Windows-x64.zip`.

Если `find_package(libobs)` / `find_package(obs-frontend-api)` не видит OBS — укажи `ObsSdk` на директорию, где доступны пакеты CMake от OBS build/install.

## Установка собранной версии
1. Закрой OBS.
2. Распакуй **собранный** `obs-smooth-zoom-Windows-x64.zip` в папку программы OBS, чтобы файлы оказались по путям `obs-plugins/64bit/obs-smooth-zoom.dll` и `data/obs-plugins/obs-smooth-zoom/zoom.effect`.
3. Запусти OBS, открой **Инструменты → OBS Smooth Zoom...**.
4. Выбери источник камеры, прокрути колесо над предпросмотром.

## Проверки
Математический модуль можно проверить без OBS:

```sh
c++ -std=c++17 tests/zoom_math_test.cpp -o zoom_math_test
./zoom_math_test
```

Плагин требует реальной сборки на Windows и испытания в OBS. Это версия 0.1 с юнит-тестами геометрии, а не проверенный готовый Windows-бинарник.
